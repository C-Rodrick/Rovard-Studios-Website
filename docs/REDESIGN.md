# ROVARD STUDIOS website: redesign handbook

Design system, motion and 3D architecture, how to maintain the site, and the test report.
The site is a static site generated by Python, with JS and CSS bundled by esbuild. There is no server and no framework at runtime.

---

## 1. Run, build, deploy

```
npm install             first time only (gsap, three, lenis, esbuild)
npm run build           bundles src/ into js/dist and css/rovard.css, then generates every page
npm run watch           rebuilds JS and CSS as you edit src/ (run `python tools/build.py` after copy changes)
python -m http.server 8000     preview at http://localhost:8000
python tools/test_site.py      the test suite (needs a server on port 8123, see section 8)
```

**Python needs:** Pillow, plus fontTools and websocket-client for `tools/fonts.py` and the test tools.

**Deployment.** Netlify publishes the repo root with no build step, so `js/dist`, `css/rovard.css` and the generated HTML are committed.
Run `npm run build` before committing. The `v2` branch is production. Nothing here has been merged or deployed.

## 3. Design system

### The idea
Everything comes from the logo's square. Corners are square, bullets are squares, the 3D object resolves into the square, the particle dust is square, and images arrive behind a blue block that slides away. That one decision is what stops this looking like a template.

### Colour (`src/css/tokens.css`)
| Token | Value | Use |
|---|---|---|
| `--blue` | `#162DAF` | The logo's own blue. Primary colour |
| `--electric` | `#245BFF` | Blue as light, in the 3D scene and shaders |
| `--ink` | `#101116` | Main dark world |
| `--paper` | `#F7F6F2` | Light world, for reading and for showing work |
| `--grey` | `#E8E8E5` | Quiet surfaces, image placeholders |
| `--yellow` | `#FFD83D` | Signal. Primary action on dark, the closing section, active states. Used sparingly |

The logo has no yellow in it. The spec's Signal Yellow replaces the older `#F5CC00` as the brand accent.

### Environments
Sections declare a world: `env-ink`, `env-paper`, `env-blue`, `env-yellow`. The home page goes ink, paper, blue, ink, paper, ink, yellow, ink, so the page has a rhythm instead of one long background.

### Typography
Display is **Syne** (variable 400 to 800), body is **Space Grotesk**, labels are **Space Mono**. All are SIL Open Font License and self-hosted in `css/fonts`. Space Grotesk was derived from Space Mono, so they belong together.
Sizes: `.d-xl`, `.d-l`, `.d-m`, `.d-s`, `.lead`, `.mono`. Only `d-xl` and `d-l` are uppercase.

### Layout
A 12-column grid inside `.wrap` (max 1520px, gutter `--gut`). Section rhythm is `--sec` and `--sec-s`. Breakpoints: phone under 760, tablet under 1100, desktop above. Cards are deliberately rare; rows, rules and open compositions do the work.

### Components
`.btn` plus `btn-y`, `btn-blue`, `btn-ink`, `btn-line`, `btn-line-d`, `btn-lg`, `btn-sm`. `.chip`, `.eyebrow`, `.frame`, `.meta`, `.st` (project status label), `.qa` (FAQ), `.cap` (capability row), `.pk` (pricing row), `.opt` (form choice).

## 4. Motion principles

Purposeful, fluid, precise. Timings and easings are in `src/js/config.js`, mirrored in `tokens.css`.

| Move | Where | How |
|---|---|---|
| Character rise | Hero only | `[data-split="chars"]` |
| Line rise | Section headlines | `[data-split="lines"]` |
| Word read | One statement on the home page | `[data-read]`, words go from 45% to 100% as you scroll, so it never drops below large-text contrast |
| Title rise | Page titles | CSS `.rise`, runs at first paint with no script to wait for |
| Quiet rise | Body content | `[data-reveal]` |
| Block wipe | Images | `[data-wipe]`, the signature move |

Only one section pins (From idea to reality, on desktop). Scroll is never hijacked; Lenis only smooths the wheel, touch stays native.

## 5. Motion and 3D architecture

```
src/js/main.js          entry, wires everything below
  config.js             timing, easing, helpers
  prefs.js              pause control (remembers choice)
  scroll.js             Lenis + ScrollTrigger on one clock, anchors
  nav.js                header, full-screen menu, focus trap
  transitions.js        View Transitions, or the blue wipe where unsupported
  intro.js              opening sequence
  type.js               SplitText moves, pointer weight field on the hero
  reveals.js            scroll entrances and block wipe
  cursor.js             context label over project links, mouse only
  media.js              film, ambient loops, lightbox
  form.js               the five-step enquiry
  work.js               filters (GSAP Flip) and the Brand Universe wall
  capabilities.js       picture follows the row
  home.js               dynamic import. Home page scroll story and Core poses
  core/quality.js       decides whether a device runs WebGL. No Three.js in this file
  core/core.js          dynamic import. The Core itself
  lab/*.js              dynamic imports. One file per Creative Dimension study
```

### ROVARD Core
A single icosphere. Its shape is computed in the vertex shader as a blend of four forms, with normals recomputed by finite differences:

- **seed** a small sphere: the idea
- **strata** stacked terraces: the thinking
- **block** a soft slab with the logo's exact 181:171 proportions, plus the logo's R extruded from the SVG path: the design
- **fluid** noise-displaced liquid: the experience

No model files and no textures. Reflections come from a procedural environment of cobalt walls and one yellow strip. `home.js` holds the poses (`P`) and phone overrides (`PHONE`). Scroll picks a target pose and the Core eases toward it on its own clock, so jumping around the page cannot break it. `difference` blending on the hero type is why letters turn yellow where they cross the object.

### Technology decisions
| Considered | Decision | Why |
|---|---|---|
| GSAP 3.15 | Used | Timelines, ScrollTrigger, SplitText, Flip. Free under GSAP's standard licence, which allows commercial sites |
| Three.js r187, WebGL 2 | Used | The Core and one study |
| WebGPURenderer | Not used | The custom vertex work relies on `onBeforeCompile`, which the WebGPU renderer does not support. It would need a rewrite in TSL, for no visible gain and a larger download |
| Lenis | Used | Wheel smoothing only |
| View Transitions | Used | Shared project image between pages in supporting browsers, blue wipe elsewhere |
| Rive | Not used | Needs `.riv` files made in the Rive editor. GSAP and SVG cover every interaction here |
| Spline | Not used | Heavy runtime, and the Core needs custom shader states |
| Sound | Not used | Optional in the brief, and retired earlier in the project |

### Loading and fallbacks
- **Opening sequence:** first visit only, about 1.4 s (faster on phones), any key or click skips it, no progress bar. A CSS animation removes it if the script fails.
- **Core:** the page never waits for it. A still image shows first and the Core fades in over it when ready. `core/quality.js` keeps the still and never downloads Three.js when there is no WebGL 2, a software renderer, under 4 GB memory, under 4 CPU cores, or Save-Data on.
- **Quality:** desktop 65k triangles and up to 1.75x resolution. Phones and tablets 12k triangles, 1.25x, no particles. A frame-time guard drops resolution, then falls back to the still.
- **Rendering stops** when no Core section is on screen, the tab is hidden or motion is paused. GPU resources are released on failure.
- **Reduced motion:** no intro, no Lenis, no scroll-linked movement, no Three.js. Stills instead; content all visible.
- **No JavaScript:** all content readable, navigation works, the form shows all five steps and posts normally. The wall becomes a horizontal scroller.
- **Pause control:** in the footer, remembered between visits.

## 6. How to change things

**Add or edit a project.** Add to `tools/projects-raw.json`, add entries in `tools/content.py` (`PROJECT_KIND`, `PLAIN`, and `CONCEPT` if it is a concept, plus `MADE` if needed). Run `python tools/images.py`, then `npm run build`.

**Show it on the home page or the wall.** Edit `SELECTED` or `UNIVERSE` in `tools/content_v3.py`.

**Label a project.** Add its slug to `CONCEPT` to label it an independent concept. Everything else makes no claim about who commissioned it.

**Change services.** Capabilities are `CAPABILITIES` in `content_v3.py`. The longer lists and service pages are `SERVICES` in `content.py` and `tools/landing.py`.

**Change prices.** `PACKAGES` in `content.py`. Grouping is `PRICE_GROUPS` in `content_v3.py`.

**Replace media.** Swap the source file, run `python tools/images.py`, rebuild. Images are served as responsive WebP from `img/`. Set `SITE['media']` to move them to a CDN.

**Regenerate Core stills** after changing the Core: start a server on 8123, `python tools/core_stills.py`.

**Add a study.** Add a file in `src/js/lab/` exporting a function that returns `{ start, stop }`, register it in `lab/index.js`, add it to `LAB` in `content_v3.py`, and give it a poster at `img/lab/<id>.webp`.

**French.** Every page is built from English plus the dictionaries. New English copy shows up in `tools/fr-missing.json`; add the French to `tools/fr/v3.json`. (Hex colour codes in that list are harmless.)

**Enquiry form.** It posts to `SITE['formspree']` in `content.py`. To change where enquiries go, change that URL or the form's settings in Formspree. Step 1 choices are `NEEDS_V3`. `/start/?need=website` and `/start/?package=brand` pre-fill it, and the older need values (such as `design`, `ads`, `unsure`) still map across.

**Motion.** To turn one effect off, remove its call in `main.js` or its `data-*` attribute in the template. To change the feel everywhere, edit `config.js`.

## 7. Audit summary

- **Architecture:** kept. The Python generator already produced good SEO, French and structured data. Replacing it with a framework would have added risk with no visible gain. Added esbuild for code splitting.
- **Kept:** all 22 projects, 12 articles, 9 service pages, legal pages, French site, SEO, sitemap, Formspree, film, showreel, logos, pricing figures.
- **Replaced:** `site.css`, `theme.css`, `motion.css`, `site.js`, `motion.js`, `hero-3d.js`.
- **Assets:** project galleries in `img/`, originals in `assets/` (208 MB, not all published), 3 film sets, 12 cut-out logos, 10 illustrative people photos (not used in this design).

## 8. Test report

Run on a Windows PC with an Intel UHD integrated GPU, Chrome headless. Lighthouse 13.6, through a local server with gzip to approximate Netlify. See `tools/test_site.py`.

| Home | **73 to 91, misses the 85 target** | 90 to 99 | 100 | 100 | 100 |
| Work | 93 | 100 | 100 | 100 | 100 |
| Project page | 94 | 100 | 100 | 100 | 100 |
| Services | 98 | 100 | 100 | 100 | 100 |
| About | 94 | 100 | 100 | 100 | 100 |
| Pricing | 93 | 100 | 100 | 100 | 100 |
| Insights | 94 | 100 | 100 | 100 | 100 |
| Start a project | 97 | 100 | 100 | 100 | 100 |
| Contact | 98 | 100 | 100 | 100 | 100 |
| Creative Dimension | 91 | 100 | 100 | 100 | 100 |

CLS is 0 on every page. Scores are from repeated local runs and vary between runs; real scores on Netlify will differ.

**Known shortfalls.** The home page is the one page under the mobile target: in the last runs it scored 75 to 79, with 370 to 590 ms of blocking time and LCP of 3.2 to 3.9 s under simulated slow 4G. That is the cost of the opening sequence and character animation on a throttled CPU. Skipping the opening sequence on phones is the obvious next thing to try. LCP also exceeds 2.5 s on Work, project pages, Insights and Creative Dimension (2.6 to 3.0 s), which open with images.

### 3D on a real GPU
Intel UHD integrated: 101 to 103 fps in the hero and the pinned section, worst frame 20 ms. Canvas stops rendering when its sections are off screen (checked).

### Behaviour
`tools/test_site.py` covers internal links and anchors on 110 pages, horizontal overflow at 390, 768, 1024 and 1440 px, runtime errors on 16 pages at desktop and phone, menu focus and Escape, every form step and error state, filters, concept labels, reduced motion, no JavaScript, first and return visit, and the pause control.

### Not tested
- **A real form submission.** The POST was intercepted in tests so your inbox was not spammed. The endpoint is unchanged, but send one real enquiry after deploying.
- **Physical phones, Safari and Firefox.** Testing was Chrome only, with phone emulation. The blue wipe path for browsers without View Transitions was not run in such a browser.
- **A screen reader.** Semantics and focus were checked by tooling only.
