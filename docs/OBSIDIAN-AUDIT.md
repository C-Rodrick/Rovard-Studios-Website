## 2. Verified brand colours

| Colour | Value | Where it was read from |
|---|---|---|
| ROVARD blue | `#162DAF` | `assets/rovard-logo.svg` and both Combined Logo SVGs (the square), and `--blue` in `styles.css` (main) and `css/site.css` (v2) |
| ROVARD yellow | `#F5CC00` | `--yellow` in `styles.css` (main) and `css/site.css` (v2) |

Two things the brief should know about:

- **The logo files contain no yellow.** They hold only the blue and `#EBEBEB`. The yellow is verified from the stylesheets of both generations of the site, where it has always been the one value. If an older brand PDF exists with another yellow, it is not in this repository.
- **The blue is too dark to read as text on obsidian** (about 1.5:1). So it is used as a surface, for button fills, for the Studio section, and as light. White on it is 10:1. Blue *text* on dark uses the proposed Ice Blue. Nothing replaces the original.

Yellow on obsidian is 13:1, and yellow text on the blue is 7:1. In the 3D, both brand colours bypass tone mapping, so the marks on the sculpture reach the screen as the exact values.

## 4. The ROVARD CORE

The idea is the brief's concept, made literal. **An idea passing through a frame and out the other side.**

- **The Frame:** an obsidian block in the proportions of the logo's blue square (181:171), hollowed, with uneven walls, broken open at one corner with raked cuts.
- **The Gate:** a slim polished frame that interlocks with it at an angle.
- **The Current:** one continuous liquid-metal form, swept along a curve, whose section swells, flattens and turns. It gathers in the opening and leaves through the break.
- **The Pane:** smoked glass that the Current passes through.
- **The Marks:** one blue channel, one yellow key and a yellow line, in the exact brand values.

Everything is generated in code (`src/core/geometry.js`). There is no downloaded asset. It has its own material (`src/core/shaders.js`) rather than a stock one: an analytic studio of softboxes gives the reflections, so there is no environment-map step to freeze the page, and the key, fill, rim, blue and yellow lights can change with each state.

One component, one state object (`src/core/states.js`): hero, recede, rest, capabilities, closing, studio, contact, each with a phone version.

The raked cut from the Frame carries through the interface: button corners, plate corners.

## 5. Decisions worth checking

- **Concepts are labelled**, as the brief says, using the existing list of 10. That reverses the choice on the current live site.
- **Client is not shown on any project**, because the repository cannot verify which of the other 12 are client work.
- **Kymela 2026** shows only its factual line. Its stored challenge text describes a brand with "inconsistent creative execution", but the work is a wedding invitation.
- **"Studio project"** is the neutral label for unclassified work.
- **Stored project text** is reused as is, including claims of intent like "confident technology brand". Older wording implying results had already been replaced in `tools/content.py`, and that replacement is kept.
- **Motion on phones:** the entry runs at about a third of the brief's delays, because testing showed the staged wait pushed LCP past target on a slow connection. Desktop follows the brief's timings.
- **The 3D starts on the first sign of a person, or after a few seconds.** The still in the HTML is a render of the same composition, so nothing looks missing meanwhile.
- **No custom cursor and no sound.** Neither added enough.

## 7. Test results

Run with `python tools/oa/test_site.py`, against `tools/oa/serve_gz.py`.

Last run: 9,556 checks passed, 0 failed. Checks: every internal link, image and anchor on all pages in both languages; one h1 and heading order; descriptions and canonicals; brand-name spelling; overflow and type staying in view at five sizes on 20 pages; console errors; keyboard use of the menu; filters, history and project navigation; the image viewer; form validation, the double-click guard, and success, server-failure and network-failure outcomes (intercepted, so nothing reached the real inbox); reduced motion, no WebGL and no JavaScript.

**Not tested:** a real submission reaching the inbox, real iOS and Android devices, Safari and Firefox, and field INP. WebGL here ran in software, so 3D frame rate on real hardware is unmeasured.

## 8. Working on it

```
npm install
npm run build                 bundle src/ and generate every page
python tools/oa/fr_gen.py     then build again, after adding French to tools/fr/obsidian.json
python tools/oa/stills.py     re-render the Core stills, after changing the sculpture (server on :8131)
python tools/oa/test_site.py  all checks (server on :8131)
```

`src/core` is the 3D, `src/js` is behaviour, `src/css` is the design system (motion tokens in `tokens.css`). Copy is in `tools/oa/oa_copy.py`.
